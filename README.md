
# Class Exercise/Lab -  Menu-Driven Calculator

Create a calculator that allows the user to repeatedly perform calculations using methods.

## Menu
===== Calculator =====
```
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit

Enter choice:
```

## Program Requirements
- Required Methods
 - - public static double add(double a, double b)
 - - public static double subtract(double a, double b)
 - - public static double multiply(double a, double b)
 - - public static double divide(double a, double b)

## Program Flow
1. Display menu
2. Read user choice
3. Ask for two numbers
4. Call appropriate method
5. Display result
6. Repeat until Exit

## Sample Run
===== Calculator =====
```
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit

Enter choice: 1

Enter first number: 10
Enter second number: 5

Result: 15.0
```
